# М12 Senior и карьера

**Цель:** мыслить как senior: проектировать системы, принимать решения, показывать результат.
**Материалы:** «Designing Data-Intensive Applications» (Kleppmann, избранные главы), «AI Engineering» (Chip Huyen), system design для ML/LLM, Pramp/interviewing.io для собеседований.

|------|--------|----------|
| Пн | Шаблон system design: требования → оценки → компоненты → компромиссы | Разобрать 1 пример |
| Вт | Масштабирование: кэш, очереди, шардинг, консистентность | Конспект и схемы |

## ✅ Критерии выхода
- [ ] Capstone в проде с README, схемой, метриками и демо
- [ ] Могу провести system design для LLM-системы за 45 минут
- [ ] CV и GitHub готовы, отправлено ≥ 10 откликов
- [ ] Самооценка по матрице: большинство пунктов на уровне Middle+, часть на Senior

## После плана (месяцы 13+)
Углубление в одну специализацию (RAG/поиск, агенты, fine-tuning/serving, evals/надёжность), работа над реальным продуктом или коммерческим проектом, выступления/статьи, вклад в open source.
