# М01 Python основы

**Цель:** уверенно писать скрипты на Python без подсказок.
**Материалы:** Python Tutorial (docs.python.org), книга «Automate the Boring Stuff», задачи на Exercism/LeetCode Easy.
**Настройка (День 1):** Python 3.12, VS Code, venv, Git, GitHub-аккаунт, репозиторий `python-practice`.
